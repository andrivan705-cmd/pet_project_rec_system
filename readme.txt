Проект
Рекомендательная система постов для социальной сети

Описание проекта
Разработка персонализированной рекомендательной системы, которая предсказывает вероятность того, что пользователь лайкнет пост, и на основе этого формирует ленту рекомендаций. Проект охватывает полный цикл создания ML-продукта: от построения моделей до их сравнения в A/B-эксперименте.

Основные этапы
1. Классическое машинное обучение (ML)
Модель: XGBoost Classifier.

Признаки: пользовательские (пол, возраст, гео, OS, источник), пост-признаки (тема, TF-IDF текста), временные (час, день недели, месяц, циклические признаки).

Результат: ROC-AUC на тесте ≈ 0.65, модель сохранена как model_control.pkl.

2. Глубокое обучение (DL)
Улучшения: добавлены эмбеддинги текстов постов (DistilBERT) с последующим снижением размерности (PCA) и кластеризацией (KMeans). Для каждого поста рассчитаны расстояния до центров кластеров.

Модель: CatBoost Classifier с поддержкой категориальных признаков (тема, кластер, гендер, страна и др.).

Результат: HitRate@5 > 0.57, что соответствует требованиям проекта. Модель сохранена как model_test.pkl.

3. A/B-тестирование
Дизайн: пользователи детерминированно разбиты на контрольную (ML-модель) и тестовую (DL-модель) группы через MD5-хэш с солью (50/50).

Сервис: FastAPI-эндпоинт /post/recommendations/ возвращает рекомендации с указанием группы пользователя (exp_group).

План анализа: подготовлены скрипты для расчёта HitRate, доли лайкнувших, среднего числа лайков; предусмотрены статистические тесты (Манна-Уитни, бакетный подход для HitRate). Ожидается подтверждение превосходства тестовой модели.

Архитектура сервиса
Фреймворк: FastAPI.

База данных: PostgreSQL (подключение через SQLAlchemy).

Загрузка моделей: модели загружаются при старте из pickle-файлов (model_control.pkl, model_test.pkl).

Логика рекомендаций: для каждого запроса определяется группа пользователя, выбирается модель, подготавливаются признаки и возвращаются топ-N постов.

Итоги и выводы
1)Разработаны две модели, причём DL-подход с эмбеддингами и кластеризацией показал значительное улучшение качества (HitRate > 0.57 против предыдущей ML-версии).

2)Реализован полноценный сервис, готовый к проведению A/B-эксперимента.

3)Спроектирован и частично реализован анализ A/B-теста, включая проверку разбиения, расчёт метрик и статистическую проверку гипотез.

Дальнейшие планы
1)Доработать анализ A/B-теста на реальных данных.

2)Внедрить более сложные нейросетевые модели (например, двухбашенные сети) для улучшения персонализации.

3)Оптимизировать скорость инференса (кэширование, batch-обработка).
